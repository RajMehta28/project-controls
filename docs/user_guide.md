# Project Controls Dashboard: one-page user guide

Sample data. Figures are cumulative to the status month shown at the top.

**The two numbers that matter**
- **CPI (cost performance index)** = value of work done / what it cost. 1.00 is on budget. 0.95 means every $1.00 spent bought $0.95 of planned work.
- **SPI (schedule performance index)** = value of work done / value planned by now. Under 1.00 is behind schedule.
- Colors: Green 0.98 and above, Amber 0.95 to 0.98, Red under 0.95.

**Forecasts**
- **EAC** (estimate at completion) = budget / CPI. What the package will cost if today's efficiency continues.
- **VAC** = budget minus EAC. Negative means a forecast overrun.
- **TCPI** = the efficiency needed on remaining work to finish on budget. Above 1.10 is usually not realistic. Blank means the budget is already spent.

**Pages**
1. *Executive Summary*: headline numbers, package table, cumulative plan vs earned vs actual curve.
2. *Cost by Package*: budget vs forecast, monthly CPI heat table, overtime vs CPI with early warnings.
3. *Schedule*: milestone variance in days (positive = late).
4. *Risk*: open risks on an impact by likelihood grid, sorted list with owners and mitigations.
5. *Cost Trends*: approved and pending trends, and what EAC becomes if pending items are approved.
6. *Cost Studies*: three short analyses, each with a question, finding, dollar impact and recommendation.

**Early warning rule**: a package is flagged when its overtime share rises at least 1 point in a month
while its monthly CPI falls at least 0.005. It points to schedule being bought with overtime.

**Updating risks**: use the risk update form. Changes show after the next refresh.

**Questions or a number looks wrong**: contact the report owner with the page name, package and month.
