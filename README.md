# Construction Project Controls BI Dashboard

**Live dashboards:** https://rajmehta28.github.io/project-controls/
- [Project Controls Dashboard (cost)](https://rajmehta28.github.io/project-controls/cost-dashboard/)
- [Planner Dashboard (schedule)](https://rajmehta28.github.io/project-controls/planner-dashboard/)

A portfolio project by Raj Chetan Mehta. It tracks cost, schedule and risk for a
sample $120M site infrastructure scope (6 work packages, Jan to Dec 2026, status month Sep 2026)
using earned value: CPI, SPI, EAC, cost and schedule variance, TCPI, plus an
overtime early-warning rule, a risk register and a cost trend log.

**All data is fictional and generated by `scripts/generate_data.py`. This project is not
affiliated with, and does not use data from, any company or real project.**

## What is in here

| Folder | What it holds |
|---|---|
| `data/` | Sample CSVs: WBS, monthly PV/EV/AC and labor hours, milestones, risk register, cost trends |
| `scripts/generate_data.py` | Rebuilds the sample data (seeded, so the same numbers every time) |
| `sql/` | PostgreSQL: schema, load, and reporting views (cumulative cost with window functions, package status, risk summary, milestone variance, overtime warning) |
| `powerbi/power_query.m` | Power Query (M) queries with ServerName / DatabaseName / SourceMode parameters (Postgres or CSV) |
| `powerbi/dax_measures.dax` | All DAX measures: CPI, SPI, EAC, ETC, VAC, TCPI, RAG status, risk closure %, overtime warning, trend exposure |
| `powerbi/model.md` | Star schema, relationships, the 6 report pages (incl. Cost Studies), template (.pbit) and gateway refresh steps |
| `paginated/monthly_cost_report.md` | Monthly paginated cost report: tested SQL datasets, layout, Report Builder steps |
| `intake/README.md` | Microsoft Forms and Power Apps risk-update intake that feeds the register |
| `scripts/validate.py` | Recomputes every KPI in pandas and cross-checks the SQL views |
| `preview/index.html` | Browser preview of the report pages (open in any browser) |
| `planner/index.html` | Planner Dashboard (simulation): Gantt vs baseline, critical path (CPM), what-if simulator, Monte Carlo finish-date risk, schedule quality checks. Built by `scripts/build_planner.py` from `data/schedule_activities.csv` |
| `docs/` | The live site (GitHub Pages): landing page and both dashboards |
| `docs/user_guide.md` | One-page guide for the people who read the dashboard |

## Run it

```bash
python scripts/generate_data.py                 # optional, data is already in data/
createdb pcbi
psql -d pcbi -f sql/01_schema.sql
psql -d pcbi -f sql/02_load.sql                 # run from this folder
psql -d pcbi -f sql/03_views.sql
python scripts/validate.py --postgres "postgresql://postgres@localhost:5432/pcbi"
```

Then build the Power BI file on Windows (see `MAC_SETUP.md` if you are on a Mac):
1. Create the parameters, then paste each query from `powerbi/power_query.m`.
2. Set relationships as in `powerbi/model.md`, add the measures from `powerbi/dax_measures.dax`.
3. Build the 6 pages from the spec, using `preview/index.html` as the visual target.
4. Check the Executive Summary shows CPI 0.975 and SPI 0.990. If not, compare with `validate.py`.

## Planner Dashboard (simulation)

16 activities with logic links, baseline dates and actuals to Sep 30, 2026, matching the milestones above.
- Critical path today: A12 Remaining utility runs > A15 Testing > A16 Turnover. Forecast Jan 08, 2027 vs Dec 31 baseline (+8 days).
- Piers finished 12 days early, but the gain became float on Foundations zone 2 (11 days), not an earlier finish.
- Monte Carlo (2,000 runs, -10% to +30% on remaining durations): P50 Jan 15, P80 Jan 21, 2027.
- What-if: recovering 8 days on A12 returns turnover to Dec 31.
- 3-week look-ahead (Oct 5 to 23): 12 tasks, 5 open constraints, 3 on the critical path, led by the large-bore pipe delivery (risk R07).
- Schedule metrics: SPI 0.990, CPLI 0.913, BEI 1.00; A10 is near-critical with 11 days of float.
- Schedule check flags one open end (A07 has no successor) and 10 activities over 60 days.
